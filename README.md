A collection of core Python programming assignments and foundational problem-solving exercises.

---

## Included Programs

1. **`factorial.py`**
   - Implements both iterative and recursive factorial calculations.
   - Includes input validation and edge-case handling for zero and negative inputs.

2. **`fibonacci.py`**
   - Generates the Fibonacci sequence up to $N$ terms.
   - Computes the $N$-th Fibonacci number with $O(N)$ time complexity and $O(1)$ space.

3. **`struct_to_dict.py`**
   - Demonstrates converting custom class structures, nested dataclasses, and objects into Python dictionaries (`dict`).

---

## How to Run

Ensure Python 3 is installed:

```bash
python factorial.py
python fibonacci.py
python struct_to_dict.py
```
